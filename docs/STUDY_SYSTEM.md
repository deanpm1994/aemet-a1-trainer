# Study System

## User schedule

Work:
- 12:30–23:00

Preferred study:
- Morning deep work
- Light night review only

## Default weekday template

- 07:30–09:00 deep technical topic
- 09:10–10:10 questions or practical case
- 10:20–11:00 legal/informatics/flashcards
- 23:30–00:00 optional light review

## Daily mission format

Each day should have:
- one main topic
- one question/practical block
- one review block
- one measurable output

## Minimum win

A day counts as successful if the user completes:
- one focused study block
- one small question/review block
- updates confidence or mistake log

## Session output checklist

- Notes created
- Questions solved
- Flashcards created
- Mistakes logged
- Topic status updated

## Focus rules

- Avoid open-ended study.
- Every session needs a timer.
- Every session needs an objective.
- Every session ends with a review decision.
- Heavy topics should be studied before work.
- Night study should be light.
