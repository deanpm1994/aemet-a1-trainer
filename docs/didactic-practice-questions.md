# Didactic Practice Questions

Reviewed didactic questions are authored practice material. They are never
official historic exam questions, even when their style is informed by past
exams or their topic is drawn from the verified BOE syllabus.

Every published item must use `didactic_reviewed` / `reviewed`, one of the
explicit selection instructions (`choose_correct` or `choose_incorrect`), four
distinct options, one keyed selectable answer, one syllabus topic, an
explanation, and an authoritative supporting source URL with retrieval date.

The topic is an internal tag only. Questions must test subject knowledge (for
example, what `ls` does in Linux), never the syllabus structure, title,
numbering, or which content belongs to a programme topic.

Run `validateDidacticQuestion` for every item and
`validateDidacticTopicCoverage` for the intended one-per-topic set before
seeding. Do not create factual questions from a syllabus title alone. The
quiz shows the source only after an answer is submitted so it cannot act as a
pre-answer hint.
