# Ground Rules

## Scope

This repository is for `AEMET A1 Trainer` only.

Primary outcomes:
- syllabus tracking
- question practice
- calendar planning
- focus improvement
- countdowns
- official monitoring
- progress analytics

## Official data rules

1. Never invent official information.
2. Mark unknown official details as `TODO_VERIFY_OFFICIAL_SOURCE`.
3. Preserve exact official wording when storing syllabus or exam content.
4. Store source URL, retrieval date, and verification status for official items.
5. Do not present unofficial material as official.
6. Do not assume future call dates, deadlines, or number of places.

## Product rules

1. Keep the first phase documentation-heavy and architecture-first.
2. Prefer placeholders over fake integrations.
3. Keep the UI mobile-friendly and PWA-ready.
4. Use mock data only when clearly labeled as unverified.
5. Avoid broad platform features unrelated to exam preparation.

## Engineering rules

1. Use TypeScript across the app.
2. Keep domain types separate from route components.
3. Prefer small components and explicit props.
4. Add tests for transformations, parsers, and business rules.
5. Do not claim monitoring, sync, auth, or persistence exist until implemented and verified.
