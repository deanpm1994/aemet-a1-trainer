# Study MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver Spanish topic guidance, topic/random quizzes with feedback, and an actionable morning-study orchestrator for all verified syllabus topics.

**Architecture:** Keep deterministic study-card, question-selection, and orchestration rules in `apps/web/lib`. The existing topic/question routes render those rules and retain existing Supabase persistence paths. Source-owned BOE fields stay immutable; didactic materials explicitly use `unverified` status.

**Tech Stack:** Next.js App Router, React, TypeScript, Vitest, existing Supabase repositories, Tailwind CSS.

## Global Constraints

- Preserve exact BOE `officialTitle`, source URL, retrieval date, and `verified` state.
- Spanish UI and study material; English remains only existing fallback infrastructure.
- Didactic cards/questions must show `Material didáctico no oficial` and use `unverified`.
- No new dependency, no exam date, no monitoring/notification claim, and no schema migration unless existing persistence cannot represent the data.
- Every production behaviour starts with a focused failing Vitest test.

```ts
const RICH_BLOCKS = new Set(["Mathematics", "Meteorology and Climatology"]);

export function getTopicStudyCard(topic: Topic): TopicStudyCard {
  const subject = topic.officialTitle.split(".")[0] || topic.officialTitle;
  return {
    topicId: topic.id,
    label: "Material didáctico no oficial",
    objectives: [`Explicar con precisión: ${subject}.`],
    checklist: ["Leer el título oficial completo.", "Definir los conceptos del tema.", "Resolver una pregunta ligada al tema."],
    reviewPrompts: ["¿Qué parte del título oficial no puedes explicar todavía?"],
    richNotes: RICH_BLOCKS.has(topic.block)
      ? ["Divide el título oficial en conceptos y relaciónalos antes de memorizar."]
      : [],
  };
}

export function buildTopicStudyCards(topics: Topic[]): TopicStudyCard[] {
  return topics.map(getTopicStudyCard);
}
```
